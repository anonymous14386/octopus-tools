The two procedures

Base b → decimal. Positional expansion: every digit is worth its face value times the base raised to its position, counting from 0 at the right.

N₁₀ = Σ dᵢ × b^i for i = 0 … n−1 1101₂ = 1×2³ + 1×2² + 0×2¹ + 1×2⁰ = 8 + 4 + 0 + 1 = 13

Decimal → base b. Repeated division. Divide by b, write down the remainder, repeat on the quotient until it reaches 0 — then read the remainders upward.

13 ÷ 2 = 6 r 1 ↑ 6 ÷ 2 = 3 r 0 │ read 3 ÷ 2 = 1 r 1 │ upward 1 ÷ 2 = 0 r 1 │ → 1101₂

The fraction. Repeated multiplication, the mirror image. Multiply by b, take the whole part as the next digit, repeat on what is left — and read downward.

0.625 × 2 = 1.25 → 1 0.250 × 2 = 0.50 → 0 0.500 × 2 = 1.00 → 1 → .101₂
The shortcut, and when it applies

When both bases are powers of two, do not go via decimal. The bits line up: three to an octal digit, four to a hex digit. Group them and read off.

1101 1010₂ → D A₁₆ (no arithmetic at all) 111 101 101₂ → 7 5 5₈

This is the method networking uses on a MAC address and on every IPv6 field, and it is what an exam is asking for when it says "convert". Going via decimal gets the same answer with working nobody uses.

Two's complement

A negative number has no minus sign in a register — it has a width and a pattern. At width n:

encode: P = 2ⁿ + x for x < 0 decode: x = P − 2ⁿ if the top bit is set P otherwise range: −2ⁿ⁻¹ … 2ⁿ⁻¹ − 1

Invert-and-add-one is the same operation, and it is the one written by hand:

-13 at 8 bits 13 = 0000 1101 invert = 1111 0010 (one's complement) add 1 = 1111 0011 → 0xF3 check: 256 + (−13) = 243 = 0xF3 ✓

The same eight bits are 243 unsigned and −13 signed. Nothing in the bits says which — the width and the mode do. Above, decimal is the value and every other base shows the stored pattern.

Powers of two

The table you end up memorising. 2¹⁰ is the one to anchor on; every subnet mask and every host count comes off it.

What this accepts

Prefixes 0b 0o 0d 0x, and the separators _, spaces and : anywhere — plus - inside a hex number, because MAC addresses are written 00-1B-44.

Digits are 0-9 then A-Z, which runs out at base 36. Anything above that needs a bracket notation like [12].[35].[7], which is a different tool, so this one refuses rather than inventing one.

A digit that does not belong to the base is named, with its position, instead of being quietly parsed into something else.
